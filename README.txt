To-Do List App
Una aplicación de lista de tareas sencilla, elegante y funcional construida exclusivamente con tecnologías web estánda Sin frameworks, sin librerías externas, solo la potencia del navegador.

🚀 Características
Añadir Tareas: Registra tus pendientes de forma rápida.

Marcar como Completado: Tacha las tareas que ya has terminado.

Eliminar Tareas: Limpia tu lista borrando lo que ya no necesitas.

Persistencia Local: Tus tareas se guardan en el localStorage del navegador (no se borran al refrescar la página).



🛠️ Tecnologías Utilizadas
HTML5: Estructura semántica.

CSS: Estilos modernos, Flexbox y transiciones.

JavaScript: Manipulación del DOM y manejo de eventos.
